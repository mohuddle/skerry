# Privacy

Skerry collects nothing.

- No account.
- No ads, analytics, or crash-upload SDK.
- v1 declares no `INTERNET` permission. Notification text and media metadata stay in memory for the live stack. They are not written to disk, not logged, not backed up.
- DataStore holds only: island on/off, charging toggle, allowlisted package names, and pill color.

There is no data to delete because there is no user data store beyond those toggles, which you can clear by uninstalling the app.

This page exists so a later Play listing can point at a real policy.
